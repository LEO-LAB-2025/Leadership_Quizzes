# LeaderLens: Leadership Quizzes

LeaderLens is a set of interactive leadership self-assessment quizzes built from the chapter instruments in the book Leadership: Theory and Practice by Peter G. Northouse.

Link:
https://leo-lab-2025.github.io/Leadership_Quizzes/

## About The Book

Leadership: Theory and Practice is widely used in leadership education and training. It presents major leadership theories and practical assessment tools so learners can reflect on their own leadership behavior.

This project brings those chapter-based instruments into a simple web format so users can:

- take assessments quickly in a browser,
- view scores and interpretations,
- compare leadership dimensions,
- and reflect on strengths and growth areas.

## About The Quizzes In This Repository

Each quiz folder corresponds to a leadership topic/chapter instrument.

- Quiz 1: Conceptualizing Leadership Questionnaire (Chapter 1)
- Quiz 3: Leadership Skills Inventory (Chapter 3)
- Quiz 4: Leadership Behavior Questionnaire
- Quiz 5: SLII Situational Leadership Questionnaire (Chapter 5)
- Quiz 6: Path-Goal Leadership Questionnaire (Chapter 6)
- Quiz 7: LMX-7 Questionnaire (Chapter 7)
- Quiz 8: Transformational Leadership Inventory (Chapter 8)
- Quiz 9: Authentic Leadership Self-Assessment Questionnaire (Chapter 9)
- Quiz 10: Servant Leadership Questionnaire (Chapter 10)
- Quiz 11: Adaptive Leadership Questionnaire (Chapter 11)
- Quiz 12: Inclusive Leadership Reflection Instrument (Chapter 12)
- Quiz 13: Followership Questionnaire (Chapter 13)
- Quiz 14: Gender-Leader Bias Questionnaire (Chapter 14)

## Purpose

This repository is intended for leadership learning, self-reflection, classroom support, and research-oriented practice exercises.
